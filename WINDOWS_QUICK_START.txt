WINDOWS QUICK START

1. Extract the project ZIP to a folder, for example:
   C:\Users\YourName\Documents\ground-turnaround-performance-analysis

2. Open that folder in File Explorer.

3. Click the folder address bar, type cmd, and press Enter.

4. Run:
   py -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   streamlit run app.py

5. Keep the data folder beside app.py. The app reads the CSV from data/.

If 'py' is not recognized, try 'python' instead. If Streamlit says the command is not found, ensure the virtual environment is activated and run:
   python -m streamlit run app.py
